PROYEK MAGANG — LANDING PAGE UNIVERSITAS ICHSAN SATYA
============================================================

Isi folder:
- index.html          : halaman utama
- style.css           : seluruh CSS (tanpa Bootstrap/Tailwind)
- images/gedung-uis.jpg : foto gedung UIS yang diberikan

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder proyek di VS Code.
3. Pastikan index.html dan style.css berada satu folder.
4. Pastikan folder images berada di dalam folder proyek.
5. Buka index.html di browser atau gunakan Live Server.

YANG SUDAH DIPENUHI:
- Header/navbar
- Hero dengan foto gedung UIS sebagai background
- Minimal 3 program studi
- Tentang kampus
- Fasilitas/layanan
- 2 testimoni contoh
- Kontak/lokasi
- Footer
- Semantic HTML
- ul/li
- link/tombol
- alt pada gambar
- CSS terpisah
- Flexbox + Grid
- Responsive dengan @media query
- Hover kartu/tombol
- Navbar sticky
- Smooth scroll
- Tombol WhatsApp melayang
- Tanpa framework
